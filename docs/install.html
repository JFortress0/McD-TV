JARVIS
INSTALL GUIDE

Install Jarvis

Jarvis is an Android TV app. It runs on Amazon Fire TV and on Android TV and Google TV devices. You install it with one link.

The install link (type it in the Downloader app):
jfortress0.github.io/McD-TV/get
Long version, if the short one does not work:
https://github.com/JFortress0/McD-TV/releases/latest/download/McD-TV.apk

Fire TV and Fire Stick

Step 1. Get the Downloader app.

  1. On the Fire TV home screen, open Find > Search.
  2. Type Downloader. Select the orange Downloader app (by AFTVnews) and select Get.

Step 2. Let Downloader install apps.

  1. Open Settings > My Fire TV.
  2. If you do not see Developer options: open About, select your device name 7 times, then press Back. "You are now a developer" shows.
  3. Open Developer options > Install unknown apps. Set Downloader to ON.

Step 3. Install Jarvis.

  1. Open Downloader. Allow it to access files if it asks.
  2. Select the address box on the Home tab. Type jfortress0.github.io/McD-TV/get and select Go.
  3. The download starts. When it finishes, select Install, then Done.
  4. Select Delete to remove the installer file. Jarvis stays installed.

Step 4. Put Jarvis on your home screen. Open Settings > Applications > Manage Installed Applications, or hold the Home button and select Apps. Find Jarvis, press the Menu button (three lines) and select Move to front.

Google TV and Android TV

Chromecast with Google TV, Google TV Streamer, NVIDIA Shield, and Sony, TCL, Hisense or Philips TVs with Google TV or Android TV.

  1. Open the Google Play Store on the TV. Search for Downloader (by AFTVnews) and install it.
  2. Turn on developer mode: Settings > System > About. Select Android TV OS build 7 times.
  3. Allow Downloader to install apps: Settings > Apps > Security & restrictions > Unknown sources. Set Downloader to on. (On some TVs this is under Settings > Device Preferences > Security & restrictions.)
  4. Open Downloader. Type jfortress0.github.io/McD-TV/get and select Go.
  5. Select Install when the download finishes.

Google TV can block apps from outside the Play Store with a "Play Protect" warning. Select More details > Install anyway.

Android phone or tablet

  1. On the phone, open this link in Chrome: Download Jarvis.
  2. Open the downloaded file. If Android asks, allow Chrome to install unknown apps, then go back and select Install.

Jarvis is made for a TV remote. It works on a phone, but some screens are easier with a remote. To set up your TV from your phone, you do not need this: use the QR code on the TV (see below).

After you install

  1. Open Jarvis. The intro plays, then the home screen shows movies and shows.
  2. Connect your phone: open Settings (the circle at the top right) > Phone & Computer Setup. Scan the QR code with your phone camera. The Jarvis Control page opens. Use it to add addons, your Live TV playlist and websites. Changes reach the TV in a few seconds.
  3. Real-Debrid (optional): Settings > Real-Debrid. The TV shows a code. On your phone, open real-debrid.com/device and type the code.
  4. Live TV (optional): on the Control page, paste your M3U playlist link in the Live TV field and save. Open Live TV on the TV.
  5. Browse on your phone: the Jarvis web app. On the Control page, tap Open Jarvis web app. Find something to watch on your phone or computer, then tap Play on TV.

Keep your Control page link private. Anyone with it can change your TV's setup. To make a new one: Phone & Computer Setup > New link.

Updates

To update, do Step 3 again with the same link. The new version installs over the old one. Your settings, history and lists stay.

If the TV says "App not installed", uninstall Jarvis first (Settings > Applications > Jarvis > Uninstall), then install again. You then need to set it up again.

Other devices

Roku, Apple TV, iPhone, iPad, Samsung (Tizen) TVs and LG (webOS) TVs cannot install Android apps, so Jarvis does not run on them.

For those TVs, plug in a Fire TV Stick 4K or a Chromecast with Google TV (about $30 to $50) and follow the steps above.
